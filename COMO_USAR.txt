📝 COMO EDITAR O SITE
==========================================================

Para fazer modificações no site, você pode:

OPÇÃO 1 - Editar Texto/Conteúdo:
---------------------------------
1. Clique com botão direito em qualquer arquivo .html
2. Abra com: Notepad++ ou Visual Studio Code
3. Procure o texto que quer mudar
4. Modifique e salve
5. Atualize a página no navegador (F5)

OPÇÃO 2 - Editar Imagens:
--------------------------
1. Vá para a pasta: wp-content/uploads/
2. Substitua as imagens mantendo o mesmo nome
3. Atualize a página no navegador (F5)

OPÇÃO 3 - Editar Estilos (Cores, Fontes):
------------------------------------------
1. Vá para a pasta: wp-content/themes/astra/
2. Edite os arquivos .css
3. Atualize a página no navegador (F5)
