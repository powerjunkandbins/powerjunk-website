⚠️ SE ALGO NÃO ESTÁ FUNCIONANDO:
═══════════════════════════════════════════════════════════════════════════

PROBLEMA: Imagens não aparecem
SOLUÇÃO:
  1. Verifique se a pasta wp-content existe
  2. Use um servidor local: python -m http.server 8000
  3. Acesse http://localhost:8000

PROBLEMA: Links não funcionam
SOLUÇÃO:
  1. Verifique se todos os arquivos .html estão na pasta
  2. Tente abrir test.html primeiro
  3. Use servidor local para melhor compatibilidade

PROBLEMA: Design quebrado
SOLUÇÃO:
  1. Use servidor local (recomendado)
  2. Verifique se os arquivos CSS em wp-content existem
  3. Tente em outro navegador (Chrome, Firefox, Edge)
